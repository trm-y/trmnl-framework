# Framework v3.4.1

Released on 2026-10-14.

## Framework Changes

- A one-line `data-clamp` keeps text that fits on TRMNL X and Kobo, instead of cutting short names to "Mary Wollstonecr..." or "E...". Previews that run the page on a scaled screen also clamp multi-line text to its line count. The OG renders exactly as before.
- Japanese, Chinese, Cyrillic, Thai and other scripts the pixel fonts lack draw at the size of the Latin text around them, instead of 1.2 to 1.4 times too large. Japanese text can use Japanese character forms and Hong Kong and Taiwan text Traditional ones, with `fallbacks-ja.css`, `fallbacks-zh-hk.css` and `fallbacks-zh-tw.css`, and the value styles fall back to a sans font instead of serif.
- Terminalize skips a layout rebuild in Firefox that only WebKit needs, so a render costs a little less CPU and draws the same pixels.
- The color manifest and the other data files stay readable through a deploy that removes the previous gem version.

## Documentation Changes

- The new Element Sizes page shows every size class for title, value, label, description, rich text and the text utility in one grid, and marks the sizes an element does not have. Each element page and Text Size link to it.
