# Framework v3.4.2

Released on 2026-10-14.

## Framework Changes

- A full view's title bar keeps its 40px height, instead of being squashed to about 36px with no-bleed and 39px with the normal bleed margin. The layout above it gives way when content needs more room.
- A table with `data-table-limit` counts the same rows at any screen scale, so previews and self-hosted servers that run the page on a scaled screen no longer hide rows that fit on TRMNL X and Kobo. The "and N more" row is measured as drawn, and is left out when it cannot fit beside a row.
